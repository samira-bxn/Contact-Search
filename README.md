# Contact Search System Using Binary Search Tree

## Project Overview
This project is a menu-driven Contact Management System developed using Java. It uses a Binary Search Tree (BST) to store and manage contact details efficiently.

## Features
- **Add Contact:** Insert a new contact with a name and phone number.
- **Search Contact:** Search for a contact by name.
- **Display Contacts:** Display all stored contacts in alphabetical order using inorder traversal.
- **Delete Contact:** Remove an existing contact while maintaining BST properties.
- **Duplicate Prevention:** Prevent insertion of duplicate contact names.
- **Empty Tree Handling:** Handle operations on an empty contact list.

## Data Structure Used
**Binary Search Tree (BST)**

Each node stores:
- Contact name
- Phone number
- Left child pointer
- Right child pointer

## How to Run

1. Make sure Java JDK is installed.
2. Open the project folder in a terminal.
3. Compile the program:

```bash
javac ContactSearchBST.java
```

4. Run the program:

```bash
java ContactSearchBST
```
